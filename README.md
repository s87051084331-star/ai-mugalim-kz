# ZEREK — ҚМЖ тапсырмалар конструкторы + пакет сатып алу сұранысы

ҚМЖ:
- мұғалім тапсырманы өзі жазады
- жеке/жұптық/топтық/бүкіл сынып жұмыс түрі
- уақыт, балл, дескриптор, бағалау
- PDF/DOCX/PPTX/TXT/CSV/PNG/JPG оқу арқылы тапсырма мәтініне қосу
- мұғалім тапсырмаларын AI ҚМЖ-ға сәйкес кезеңге енгізеді
- DOCX экспорт
- Print/PDF
- архив/ресурс/слайд бұрынғыдай

Пакеттер:
- тіркелген мұғалім өз аккаунтынан пакет сұранысын жібереді
- payment_requests PostgreSQL-да сақталады
- admin төлемді растағанда ғана лимит қосылады
- Standard / Pro / OpenAI+100 / Gemini+100
- нақты карта/Kaspi/FreedomPay автоматты төлемі әзірге ҚОСЫЛМАҒАН; merchant credentials және webhook келісімінен кейін қосылады.
