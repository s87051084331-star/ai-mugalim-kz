# ZEREK V5.2 — Ұстаз AI интерфейсі

V5.1 backend және барлық модульдер сақталған.

Жаңасы:
- ChatGPT тәрізді орталық Ұстаз AI чат
- сол жақ тұрақты навигация
- жылдам әрекеттер
- чаттан ҚМЖ/тапсырма/слайд/архивке өту
- мобильді responsive режим
- /api/zerek/chat endpoint

Маңызды: PostgreSQL, тіркелу, рұқсат, пакеттер, ҚМЖ, архив, тапсырма банкі, ортақ база, сыныптар, QR, мониторинг, топқа бөлу, журнал және басқа V5.1 функциялары өшірілген жоқ.
