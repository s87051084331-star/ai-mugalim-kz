# ZEREK — Архив + ҚМЖ құрастыру + Ресурстар + Слайд

Қосылды:
- әр мұғалімнің PostgreSQL жеке архиві
- архивті қайта ашу AI кредит жұмсамайды
- ҚМЖ генераторы: Сабақ кезеңі/Уақыт, Педагог әрекеті, Оқушы әрекеті, Бағалау, Ресурстар
- Құндылық және Аптаның дәйексөзі қолмен енгізіледі
- мұғалімнің жеке ресурс кітапханасы (сілтеме/сурет/видео/құжат/презентация)
- AI ҚМЖ жасағанда мұғалім ресурстарын ескереді
- ҚМЖ-дан браузерлік 16:9 слайдтар
- толық экран және PNG экспорт
- бұрынғы PostgreSQL plans / OpenAI+Gemini жеке лимиттері сақталған

Ескерту: бұл нұсқада ресурс кітапханасы URL/метадерек сақтайды; файлдың өзін тұрақты сақтау үшін кейін object storage (S3/R2) қосу керек.
