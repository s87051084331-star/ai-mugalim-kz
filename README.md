# AI Мұғалім көмекшісі — ҚМЖ суреттері

Қосылды:
- DOCX ішіндегі суреттерді шығару
- PPTX слайд суреттерін шығару
- XLSX енгізілген суреттерін шығару
- pypdf қолдайтын PDF embedded image шығару
- «ҚМЖ суреттері» галереясы
- Суретті нақты тапсырмаға қолмен тіркеу
- Тіркелген сурет HTML тапсырма, топтық жұмыс және экран режимінде көрінеді
- Суретті жеке толық экранға шығару

Ескерту: скан PDF-дегі толық бет суреттері embedded image ретінде әрдайым алынбауы мүмкін; оған бөлек PDF page-render/OCR модулі қажет.
