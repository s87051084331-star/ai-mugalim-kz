# AI Мұғалім көмекшісі — прототип

## Іске қосу
1. Python 3.10+ орнатыңыз.
2. Терминалда осы папкаға кіріңіз.
3. `pip install -r requirements.txt`
4. `uvicorn app:app --reload`
5. Браузерден `http://127.0.0.1:8000` ашыңыз.

## Бар мүмкіндіктер
- 30 оқушыға арналған панель
- PDF/DOCX/XLSX/PPTX/TXT/CSV оқу
- ҚМЖ мақсаты мен дескрипторларын сақтау
- Қазақша Web Speech API қолдаса, аудио жауапты мәтінге түсіру
- Дескриптор бойынша прототиптік балл ұсыну
- Мұғалімнің балды растауы
- Камера және қатысу таймері
- CSV журнал экспорты
- Деректердің бір бөлігі браузердің localStorage жадында сақталады

## Маңызды
Бұл оқу прототипі. Қазіргі талдау — қарапайым мәтіндік сәйкестік алгоритмі, толық LLM/AI емес.
Нақты мектеп қолданысына енгізер алдында аутентификация, деректер базасы, рөлдер, шифрлау,
келісім/құпиялық, журналдау және сенімді бағалау саясаты қажет.
Оқушыны бет-жүзінен автоматты сәйкестендіру бұл нұсқаға әдейі қосылмаған; ID/QR тәсілі ұсынылады.


## QR қатысу жаңартуы
- 30 оқушыға жеке QR жасау
- QR-ды камерамен оқу
- келу уақытын автоматты сақтау
- келген/келмеген тізімі
- қолмен түзету
- QR басып шығару

QR кітапханалары CDN арқылы жүктелетіндіктен, QR функциясын алғаш қолданғанда интернет қажет.


## Сыныпты басқару
- Оқушы аттарын қолмен қосу/өзгерту/өшіру
- CSV/TXT тізімін импорттау
- ID автоматты тағайындау
- QR, қатысу, жауап талдауы және журналмен бір тізім арқылы байланысу


## v3 импорт
Оқушы тізімі XLSX, CSV және TXT форматында тікелей импортталады. Backend баған атауын (Аты-жөні, ФИО, Оқушы, Name) автоматты іздейді; табылмаса, аты-жөнге көбірек ұқсайтын бағанды таңдайды.
